# 作业提醒：登录、账号管理、课表与作业

React + TypeScript + Vite 前端，Node.js 内置 HTTP + SQLite 后端。复用本机已有环境，本次功能没有新增软件或第三方依赖。支持电脑和手机浏览器，整体采用莫兰迪色系。

## 启动

现有项目依赖已经安装，直接运行：

```sh
npm run dev
```

同时启动前端 http://localhost:5173 和后端 http://127.0.0.1:3001。接口由前端代理，浏览器仅需访问前端地址。

```sh
npm run build
npm start
```

以上用于构建并运行本机整合版本，访问 http://localhost:3001。默认只监听本机。

## 个人工作台

登录默认进入工作台，排除今天，跳过无课日期，显示本人最近三个有课日期的卡片和距离上课天数。同一天所有课程一起展示，支持已导入的后续学期。

“我的课表”只查看日、周、月等课表；导入、删除、调整安排统一在“课表管理”。工作台展示待做作业中排序后的前3项，常用网站和快捷链接继续预留。

## 课表功能与第一次使用

- 管理员兼具学生身份，可在个人中心使用自己的课表；通过应用外层切换到独立管理工作台维护课程和账号。普通学生只看到个人中心，课表内容内不出现管理按钮。
- 一人每学期一份课表。外部 AI 结果、Excel、管理员模板、课程卡片四选一；更换来源前删除本人本学期原课表。
- 学期、教学日历和作息仅由管理员统一设置。学生进入后自动使用当前学期直接导入，无需维护或先选择学期；历史浏览通过“查看其他学期”。
- AI 整理导入采用两步流程：复制提示词和学校“我的课程”整页文字交给豆包或其他 AI，再粘贴【课表开始】至【课表结束】的结果，点击“查看安排”，核对日期、时间和地点后确认保存。网站不内置 AI，仍兼容旧 JSON。Excel 支持 XLS / XLSX，多文件需属于同一目标学期。
- 管理员在“课表模板→导入模板”为不同同学的课表分别命名并导入，可保存多份模板。课程卡片自动生成，同学期同上课班复用一张卡片；不同班号保留不同卡片，信息不足提示核对。独立“公共课程”页面已取消。
- 学生可搜索、拖选卡片，手机可点击加入、移除；个人导入不会产生公共卡片。
- 个人安排优先，未覆盖部分跟随公共更新；可恢复公共安排。默认定位当前学期和今天，支持日、周、月、学期视图。
- 管理员可复制校历提取提示词，将图片交给外部 AI，粘贴结果后自动填写学期，并生成按周校历、教学周、14 节等完整作息和事项清单供核对。图片选择仅用于本机核对，网站没有内置 AI 或 OCR。

首次使用，管理员在“课程管理 → 学期与作息”建立真实学期，填写起止日期、教学周起算日和节次时间，再在“课表模板”分别导入不同同学的课表并命名。学生进入“课表管理”选择一种来源并确认，再到“我的课表”查看或在工作台查看后续上课日。

建立学期默认使用一次导入流程：复制完整提示词，把图片交给外部 AI，粘贴完整结果或选择结果文件后自动解析，直接显示学期摘要、教学周、全部作息与校历核对表。核对后点一次“确认无误并保存”，无需逐项填写或选择。手动修正为默认收起的可选入口。

可点“载入本次校历示例”查看用户提供的 2026—2027 秋冬校历。示例只填草稿。学校通用考试、寒假说明与非全日制上课日期重叠时保留核对提示，不自动取消或移动课程。

尚未预置学校日历，缺少周次或时间的课程保留为“待安排”，不会猜测排课。复杂旧 XLS 如果字符串跨记录，页面会提示另存为 XLSX。已提供的两份 XLS 已分别验证可解析。

## 作业功能

- 学委切换到“管理工作台 → 作业管理”，选择已配置学期，手动新增或导入 Excel。手动字段对应原表的序号、课程、学分、老师、作业内容、截止日期、平台、考核、组队和备注。课程名称为可搜索下拉框，输入前几个字筛选当前管理学期的课程，选中后带入任课老师和上课班；同名课程按老师、班号区分。
- 支持提供的 .xlsx 多工作表、合并单元格、英语详细课次和 WPS 单元格图片。上传后先预览核对，勾选确认后保存；重复记录跳过，原记录通过编辑更新。
- 按目标学期和上课班发布。只有课程加老师匹配唯一候选班级时默认选中发布；多候选或无候选默认草稿，可核对选择或填入准确班号后发布。
- 个人中心“我的作业”合并已选上课班的课程作业和本人添加的个人作业，支持筛选、搜索、查看内容、标记完成与撤销。新增个人作业仅自己可见，可编辑或确认删除；课程、老师和内容可选填，不要求先选班。个人作业同样参与优先级、计划时间及工作台前3项排序。
- 用户可设置高、普通、低优先级及自己的计划完成时间。学委原截止始终保留显示，个人安排单独保存；工作台取未完成作业中排序后的前3项，先优先级，再个人计划时间，未设置则沿用学委截止。
- 所给原表已在独立内存数据库验证：29项作业、12组考核说明、16张图片。未把样例自动发布到实际账号，正式使用请先核对上课班。
- 一期不做在线交作业、手机后台推送或微信通知。

[作业逐功能规则与流程图](需求文档/作业功能/文档目录.md)

作业页的“完成并停止提醒”会保存到本人账号，移出待做列表和工作台；重复点击保持完成，也可主动撤销。新增站内完成链接与通用手机完成动作约定，未登录先登录，旧通知需核对最新作业版本。发送前检查入口每次重新读取完成状态，已完成不再成为提醒候选。手机发送及具体系统通知按钮仍待接通，当前未发送真实通知。

## 个人提醒设置

个人中心新增“提醒设置”，学生及管理员个人身份均可维护本人的上课提前时间、课程变动通知、作业更新通知和截止提醒偏好。截止提醒可分别选择学委原截止和个人计划；每次调整自动保存到账号，支持版本冲突提示与失败重试。

本期仅完成设置与持久化，页面明确显示手机通知尚未接通。不申请设备通知权限，不执行定时发送；实际接收渠道与手机开启教程后续再接通提供。没有新增软件或第三方依赖。

## 数据

数据库：data/homework.sqlite。data/ 已加入忽略清单，账号不会因重启服务而丢失。备份时先停止服务，再复制整个 data 目录。不要删除数据库文件来重置服务。

同一数据库保存学期、公共课程、模板、个人课表及覆盖、作业与图片、个人优先级和计划、个人完成版本。作业开发前在 data/backups 保留了额外备份。课表开发前已在 data/backups 中保留数据库备份，已有账号继续使用。

DATABASE_PATH 可指定数据库路径，API_PORT 可指定后端端口。若改变开发端口，需同时调整代理和 APP_ORIGIN；线上已设置 APP_ORIGIN、COOKIE_SECURE=1 及显式本机代理信任，按访问 IP 分别限流。生产数据位于 /var/lib/homework/homework.sqlite，服务重启保留数据。

首位管理员通过 node server/manage.mjs init-admin 初始化，初始化信息从不回显的标准输入读取，已有管理员时会拒绝重复初始化。日常账号管理使用系统设置，无需再执行初始化。
