# MEM2602 文档维护

当前功能总表、规格说明及两类流程的统一更新入口：

```powershell
python scripts/docs/update-current-documents.py
```

功能数据保存在该脚本的 `FEATURES` 中；修改同一功能的规则、业务步骤、系统步骤后重新生成。脚本只写文档，不打开实际数据库、不启动服务、不发布线上内容。

输出位置：

- `需求文档/功能表/MEM2602功能总表.md`
- 各模块的 `需求规格说明书/`、`流程图/业务流程图/`、`流程图/系统流程图/`
- 同模块的 `流程图源文件/业务流程图/`、`流程图源文件/系统流程图/`
- 根目录及各模块 `文档目录.md`

SVG 和 Mermaid 使用同一份节点、连线数据；生成时核对文件、XML、源码引用和目录链接。

旧的 `generate-*`、`revise-*` 等脚本是历史阶段的生成器，部分包含已停用规则，不应单独用它们覆盖当前正式文档。如需重建历史基础文档，最后必须执行当前更新入口。讨论稿和版本更新说明保留历史，不作为当前功能依据。
