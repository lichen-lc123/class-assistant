# 功能发布与数据保护需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：维护人员；服务器部署。

入口：本地检查 → GitHub → 服务器程序发布。

## 当前规则

1. 只提交和上传源码、构建资源及必要说明，禁止带入电脑数据库、账号数据、真实附件、环境配置或私钥。
2. 服务器维持原数据库及已有附件；先在服务器内部生成一致性备份，在副本验证兼容性，再短暂停服备份并切换程序。
3. 程序发布不运行历史课程整理或重新导入；对已有业务表逐表核对内容摘要和附件字节，新功能表应为空。登录续期按新功能处理，不计为维护内容改写。
4. 校验失败回退到原程序及本次服务器备份；记录提交号、上版位置、备份位置、更新时间和更新点。
5. 旧记录通过当前读取逻辑显示新字段和已有附件；原来未保存的文件需补传，禁止从本地旧数据库覆盖。

## 接口与数据

scripts/deploy-program-only.sh；scripts/content-fingerprint.mjs；scripts/verify-production.mjs

正式数据保存在 /var/lib/homework，发布目录独立；文件摘要不包含明文用户信息。
