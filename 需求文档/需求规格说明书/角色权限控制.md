# 角色权限控制需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：普通用户、全部管理员；管理入口仅电脑端。

入口：电脑端管理工作台／个人功能。

## 当前规则

1. 全部管理员的公共管理权限、课程、模板和课程作业内容一致，不按创建者隔离查看、编辑、发布、现有删除或全部完成操作。
2. 学生没有管理权限；后端每次校验实际会话、当前角色与首次改密状态，隐藏菜单不能代替接口鉴权。
3. 手机页面仅保留普通用户功能，管理员在手机上使用自己的个人功能；不提供手机管理工作台。
4. 个人作业、个人计划与完成例外仍归本人；管理员身份不授权读取其他人的私人作业。管理员个人中心也必须选入对应课程才看到课程作业。

## 接口与数据

/api/admin/*；个人作业及附件接口

users.role、must_change_password、sessions；owner_id 与 created_by 含义不同。
