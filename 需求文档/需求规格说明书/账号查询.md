# 账号查询需求规格说明书

功能编号：F04  |  版本：V1.0  |  更新日期：2026-11-02  |  状态：已实现

## 功能目标

管理员查看账号列表并按学号或姓名查找账号。

## 使用者与前置条件

- 使用者：管理员。
- 前置条件：已登录且已完成初始密码修改。

## 输入与输出

| 项目 | 内容 |
|---|---|
| 输入 | 进入系统设置；可输入学号或姓名，可点击刷新。 |
| 输出 | 账号列表、角色、密码状态和账号数量。 |

## 业务规则

1. 列表展示学号、姓名、角色与“待修改初始密码 / 已设置”，不展示密码。
2. 页面的搜索为本次已加载列表的本地筛选，学号和姓名支持包含匹配。
3. 列表按账号 ID 倒序返回；页面统计全部账号、学生和管理员数量。
4. 一期列表不分页；后端另支持 search 参数查询。

## 异常处理

- 会话失效返回登录页；学生请求管理接口被拒绝。
- 加载失败显示提示；搜索无结果显示空状态。

## 验收标准

1. 管理员能查看已有账号并搜索对应学号或姓名。
2. 学生不能获得账号列表。
3. 列表及响应中没有密码或密码哈希。

## 系统接口与数据

- 入口：GET /api/admin/users；可选 ?search=关键词
- 数据处理：读取 users 的公开字段，不读取 password_hash 返回客户端。
