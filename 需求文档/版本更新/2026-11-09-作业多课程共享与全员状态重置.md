# 作业多课程共享与全员状态重置

本轮功能及验证记录随 GitHub 分支发布，服务器使用仅程序部署并校验原数据内容不变。

- 作业表没有明确上课时间时，同一学期、同课程名、同老师的不同时段课程共用一条作业（工程管理导论保持现有日期、时间对应关系，暂不扩展）。后补课程继续自动关联，不复制作业或附件。
- 表格明确提供上课日期、星期或钟点时按实际约束核对；仍不明确的内容保留草稿，不猜测适用课程。
- 管理员适用课程选择支持多选、查看已选和移除；人工选择明确范围后不自动扩大。
- 截止日期和时间可不填，仍允许发布，显示“截止时间待通知”。
- 全部完成后增加全部未完成按钮，两者均需确认并校验版本及策略代次。当前和以后选课用户采用本次默认状态，个人仍可自行调整；计划和优先级保留。
- 缺失课程/老师、未知作业字段、无法判断的表结构、错误或矛盾截止等可读取内容保留草稿及原文。管理员明确核对后发布；损坏、超限或不安全文件仍明确拒绝。
- 同步功能总表、业务流程、系统流程及 Mermaid 源文件。未将本地数据库或附件数据上传到 Git 或服务器。
