# 作业图片与附件需求规格说明书

日期：2026-11-06；版本：V1.0；本次修改已在本机实现，线上需另行更新。

角色：用户上传自己的个人作业资料，管理员上传课程作业资料；查看权限跟随作业

## 功能规则

1. 个人作业和管理员作业编辑均提供添加图片、添加附件。支持多选，保存前列出文件名、大小和图片缩略图，并可移除。关闭未保存弹框不写入文件。
2. 图片支持PNG、JPG、WebP，单张最多5MB；普通文件单个最多10MB。手动编辑页面每项最多选择20个文件，作业所有图片和附件的实际字节合计不超过20MB。读取过程中禁止保存和重复选取；超限、空文件和无效图片明确提示。历史表格图片继续保留，不下载外链。
3. 图片在作业卡片和详情中显示，可点击查看原图；普通附件独立显示文件名和大小，点击下载。工作台详情复用同一展示。普通文件始终以下载响应返回，不在网站中执行HTML等文件内容。
4. 私人作业附件仅创建者本人能读取和维护，管理员也不能获取其他人的私人附件。课程作业附件仅对应课程的授权用户及管理员可读取；每次下载都检查当前作业与文件关联，知道文件摘要不能绕过权限。
5. 新增文件必须随当前保存请求提供经过校验的原始字节。已有附件只能在原作业上保留，不能通过填入其他作业的文件摘要盗用资料。编辑时不必重新上传已保留的文件；移除关联后，该文件在原作业的旧链接失效，其他作业引用不受影响。
6. 作业字段、附件及关联在同一事务保存；失败回滚。文件保存于现有SQLite，重启后仍可读取；不增加软件、第三方依赖或独立存储服务。课程作业的正文可以为图片或附件，不强制另填重复文字。

## 数据流转与保存

复用homework_assets存放文件摘要、检测后的MIME和原始BLOB，homework_attachments保存作业、文件和字段关联。payload_json的attachment_names保存该作业内的文件名称；不同作业可以为相同字节使用不同名称，不新增表。读取返回filename、size、mime及授权URL；请求体最多32MB以容纳base64，实际文件字节仍受20MB限制。

接口：

- `POST /api/homework/personal`
- `PUT /api/homework/personal/:id`
- `POST /api/admin/homework/records`
- `PUT /api/admin/homework/records/:id`
- `POST /api/admin/homework/import`
- `GET /api/homework/assets/:assetId?recordId=…&field=…&download=1`

## 验收标准

- 私人图片和附件仅本人可读取，授权课程附件可下载，未选课程用户被拒绝。
- 文件名称和字节保存正确；中文名称下载正常，普通文件强制下载并带nosniff。
- 编辑保留、移除、错误摘要、伪装图片和超限上传均经过验证；错误不留下半份作业。
- 已有Excel图片、个人课程选择、作业完成与优先级规则继续有效。
