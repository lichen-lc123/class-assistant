# 个人作业新增与维护需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：仅本人；电脑和手机。

入口：我的作业 → 新增个人作业。

## 当前规则

1. 只能选择本人对应学期课表中的课程；选课后自动带出老师，不能伪造任意课程或他人选课。没有课程时先导入课表。
2. 支持标题、正文、截止、提交方式、备注、图片和附件；个人记录仅自己可见，管理员也不能从公共管理入口获取他人的私人作业。
3. 可编辑、确认删除、设置优先级与计划时间、切换完成；与课程作业一起参与个人列表和工作台排序。
4. 保留历史关联课程已移除的私人记录，继续编辑须符合原关联兼容规则；新建或改选仍必须选择本人当前课表课程。

## 接口与数据

POST /api/homework/personal；PUT/DELETE /api/homework/personal/:id；GET /api/homework/courses

homework_records.owner_id、course_entry_id；仅私人身份可见。
