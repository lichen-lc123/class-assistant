# 管理员批量删除作业需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：全部管理员；仅电脑端。

入口：作业管理 → 勾选记录或全选当前结果 → 批量删除。

## 当前规则

1. 可以选择当前学期中由任意管理员维护的公共作业或考核记录；不包含私人作业。每次 1—500 项。
2. 删除前明确确认范围，每项提交记录 ID 和版本；任一项失效或跨学期时整批拒绝。
3. 事务删除所选记录及其依赖关联，不删除课程、模板、用户或未选中的作业。

## 接口与数据

POST /api/admin/homework/batch-delete

沿用外键级联，不删除公共课程及账号。
