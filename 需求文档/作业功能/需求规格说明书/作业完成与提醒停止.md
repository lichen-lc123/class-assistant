# 作业完成与提醒停止需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：普通用户及管理员的个人身份；电脑和手机。

入口：工作台、我的作业或课程详情。

## 当前规则

1. 圆圈对号或完成按钮提交本人当前版本的完成状态，成功后退出工作台待做列表并更新数量。已完成在完成时间倒序列表中查看，可恢复未完成。
2. 完成和撤销都是显式状态提交，不使用盲目翻转；同版本重复完成保持幂等，旧版本拒绝。
3. 管理员全员默认完成也属于完成状态，用户可保存本代次的未完成例外；不改变其他人的状态。
4. 表格更新同一作业保留既有完成状态和个人安排；普通内容编辑按当前版本规则提示核对。不能笼统宣称所有更新都会重置个人完成。
5. 完成不等于已向教师提交，系统尚未接通微信、短信、邮件或手机后台通知；提醒候选校验不能写成已发送通知。

## 接口与数据

POST /api/homework/records/:id/completion；GET /api/homework/summary

homework_completions、homework_completion_defaults、homework_completion_exceptions。
