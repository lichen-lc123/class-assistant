# 未识别内容草稿核对需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：全部管理员；仅电脑管理；同学只查看确认发布内容。

入口：作业 Excel 导入预览／草稿筛选。

## 当前规则

1. 可读取但无法可靠确定业务含义的内容保留为草稿，包括缺少课程或老师、未识别的作业表头或额外字段、无效或矛盾截止说明、未成功提取的图片文件占位内容。
2. 保留原始文字及已提取的附件，草稿显示待核对原因。空表和明确非作业校历、作息不制造作业；作业内容为“无”仍不生成作业。
3. 管理员编辑补充课程和内容后，明确勾选已核对，再独立点击发布。待核对标记不能被课程补齐或自动匹配绕过。
4. 没有截止日期、仅有日期无时刻或原表写待通知均允许发布，显示截止时间待通知；损坏、加密或不安全的文件明确报错，不将不可读文件冒充已成功导入。

## 接口与数据

POST /api/admin/homework/preview；POST /api/admin/homework/import；编辑与发布接口

review_required、review_reasons 保存在作业载荷，不新增用户数据表。
