# 管理员全部完成需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：全部管理员；仅电脑端公共作业卡片。

入口：作业管理 → 单项卡片内部底部 → 全部完成。

## 当前规则

1. 仅已发布的课程作业可操作；考核说明、草稿及他人私人作业不支持。所有管理员均可操作其他管理员维护的课程作业。
2. 点击后弹框确认，提交当前作业版本及全员策略代次；确认后当前和以后选入对应课程的用户默认已完成。
3. 用户仍可自行改为未完成或再次完成；只影响自己的状态，不改变其他同学。
4. 再次执行全部完成会产生新代次，先前恢复未完成的用户也重新默认完成。旧页面、旧版本或旧代次请求不得覆盖新操作。
5. 设置全部完成后提供“全部未完成”，确认后当前及后续选课用户默认未完成。用户仍能自行再完成；旧的个人完成不能覆盖管理员最新重置策略。
6. 不修改作业正文、课程、账号、个人计划或优先级；重复导入更新内容时保留全员完成策略与个人选择。

## 接口与数据

POST /api/admin/homework/records/:id/complete-all（completed=true/false）；POST /api/homework/records/:id/completion

沿用默认策略和代次表；默认状态保存在作业元数据 all_students_completed，历史未保存时兼容已完成。原个人计划和优先级不变。
