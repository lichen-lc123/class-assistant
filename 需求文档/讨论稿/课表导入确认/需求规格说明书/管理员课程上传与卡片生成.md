# 管理员课程上传与卡片生成需求说明

版本：V0.5；日期：2026-11-02；状态：待确认，未开发。

## 角色与权限

- 只有管理员可以上传、维护公共课程及公共课程卡片。
- 学生只能搜索、预览、加入或移除管理员已发布的卡片；移除只改变本人课表。
- 学生通过外部 AI 或 Excel 导入的个人课程，不生成公共卡片，不修改公共课程库。
- 后端校验管理员身份，不能只通过隐藏学生端按钮限制权限。

## 上传选项

管理员课程上传表单提供“自动生成课程卡片”复选框，默认勾选。管理员预览课程并确认上传后，系统按该选项处理。

| 情况 | 公共课程 | 对应卡片 |
|---|---|---|
| 默认勾选并确认有效课程 | 保存 | 按具体上课班自动生成，发布后供学生使用 |
| 取消勾选并确认有效课程 | 保存，仍可用于管理员模板 | 不为新课程生成卡片，学生卡片搜索不显示该新课程 |
| 校验失败或取消确认 | 不写入本次新课程 | 不生成卡片 |
| 普通用户请求生成公共卡片 | 拒绝公共上传操作 | 不生成卡片 |

## 业务规则

1. 卡片由课程、具体上课班和学期信息生成，不要求学生制作或上传卡片。
2. 上课班身份需要确认。时间地点待通知的课程可以保留待安排标签，不能编造具体日期或时间。
3. 同一上课班不因重复上传而重复创建卡片；重新上传需预览已有数据。
4. 本次取消自动生成只表示不新增卡片，不自动删除已经存在的卡片。
5. 课程数据保存和需要生成的卡片一并保存，失败时不留下本次不完整写入；仅发布的卡片供学生搜索。
6. 卡片可用性与模板课程可用性分别处理：未生成卡片不代表删除课程或禁止模板使用。
7. 上传结果展示成功课程数量和生成卡片数量，未勾选时新增卡片数量为零。
8. 学生使用卡片组课仍受“每人每学期一种建立来源”限制，拖动不修改公共课程安排。

## 验收标准

1. 管理员打开上传表单时，“自动生成课程卡片”已勾选；学生不能进入公共课程上传或卡片生成入口。
2. 保持勾选并成功上传时生成相应卡片；取消勾选时课程保存但不新增卡片。
3. 学生个人导入不产生公共卡片；卡片搜索仅返回管理员发布的卡片。
4. 重复上课班不产生重复卡片，取消勾选不误删已有卡片。
