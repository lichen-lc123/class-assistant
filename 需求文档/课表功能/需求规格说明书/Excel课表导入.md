# Excel课表导入需求规格说明书

版本：V1.0；日期：2026-11-02；状态：前后端已实现，本机运行。

角色：学生、管理员。

输入：同一目标学期的一个或多个 XLS / XLSX 文件。

输出：课程和排课候选预览，确认后保存到个人课表；管理员导入则保存独立命名模板，并自动生成去重课程卡片。

## 业务规则

1. 一次 1—5 个文件，单个不超过 2MB，总计不超过 6MB；仅接收 XLS / XLSX。
2. 识别课程名称、编号、老师、学年学期、时间地点、备注等表头，保留原始行以供核对。编号保留为字符串。
3. 多文件需属于所选学期；秋、冬资料是否同属一个学期，由管理员依据学校规定配置别名，不因同属一个学年直接合并。
4. XLS 使用内置 BIFF8 解析，XLSX 使用 ZIP/XML 解析，无需安装 Excel。复杂旧 XLS 字符串跨记录时明确提示另存为 XLSX，不悄悄截断。
5. 学校导出表中“自定义”、缺少周次或缺少实际时间的情况保留待安排，用户在预览补充；不能从文件推断不存在的日历。
6. 预览校验、按班号匹配、确认提示和同来源补充规则与 AI 导入一致。学生上传仅影响本人。

## 数据与系统处理

文件在请求中解析，不作为公开文件存储；结构化资料写入个人条目或管理员确认后的公共课程。

接口：

- `POST /api/timetable/preview（source=excel）`
- `POST /api/timetable/:termId（source=excel）`
- `POST /api/admin/timetable/template-preview（管理员模板预览）`
- `POST /api/admin/timetable/template-import（确认模板及自动去重卡片）`

后端统一校验登录、角色、用户归属、目标学期和数据格式；有问题的预览需确认，写入按事务完成。

## 验收要点

- 已提供的两个旧 XLS 可分别识别其秋、冬资料，缺少周次时不会编造日期。
- 损坏或跨学期文件显示原因，未经确认不保存个人课程。
