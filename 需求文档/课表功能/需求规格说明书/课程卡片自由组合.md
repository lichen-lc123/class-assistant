# 课程卡片自由组合需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：本人；电脑和手机。

入口：课表管理 → 课程卡片组合。

## 当前规则

1. 搜索课程或老师；点击卡片整体加入右侧，电脑也可拖拽；不再显示“加入我的课程”文字按钮及课程编号。
2. 右侧为本次待新增课程，已有课表保留。检查并预览打开本学期月度课程安排，允许核对已有加新增的整体安排。
3. 不展示排课说明、待核对信息等非必要说明；时间冲突必须明确提示并阻止提交。
4. 预览及保存都重新校验时间占用、批次内部冲突和旧版本；选择不同卡片时仍需与先前通过模板导入的课程比较。

## 接口与数据

GET /api/timetable/cards；POST /api/timetable/:termId

复用公共课程 ID 和个人 timetable_entries，不复制一份公共卡片。
