# 个人优先与公共同步需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：本人调整；管理员维护公共基值。

入口：课表管理 → 调整个人安排。

## 当前规则

1. 用户可以调整自己的日期、时间和地点；公共基值与个人覆盖分开存储，不反写模板或卡片。
2. 自动生成课程的模板和卡片更新同步引用用户；手动卡片与加入模板时的独立快照按来源区分同步范围。
3. 用户编辑模板课程后保存整门课程快照，名称、老师、时间和地点不再被模板或公共卡片后续更新覆盖；只改教室也适用。其他未修改课程继续同步。直接卡片选课维持原有个人覆盖规则。
4. 主动移除模板课程时按本人课表、模板、课程记录排除，模板改名、更新或增删成员不补回该课；多个既有模板来源一并记录。明确重新添加或恢复默认安排时按用户操作恢复。
5. 兼容已有个人覆盖及能确认版本的历史移除；启动只创建空策略表，不批量重写旧内容。历史意图无法确认时不伪造用户操作。
6. 编辑课次自动编号、日期计算周次和星期，新增沿用首节地点和时间并滚动定位；弹框顶部固定，仅内容区域滚动。

## 接口与数据

GET /api/timetable/:termId；个人课程覆盖接口

timetable_entries 的 base_snapshot_json、private_json、override_json、base_revision；timetable_template_course_choices 按本人课表、模板、课程记录 edited/removed。
