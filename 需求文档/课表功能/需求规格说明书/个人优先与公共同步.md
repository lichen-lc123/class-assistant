# 个人优先与公共同步需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：本人调整；管理员维护公共基值。

入口：课表管理 → 调整个人安排。

## 当前规则

1. 用户可以调整自己的日期、时间和地点；公共基值与个人覆盖分开存储，不反写模板或卡片。
2. 自动生成课程的模板和卡片更新同步引用用户；手动卡片与加入模板时的独立快照按来源区分同步范围。
3. 只改地点不冻结公共时间；用户主动修改时间组后，该组个人安排优先。公共课次变化时提示重新核对已有个人覆盖。
4. 编辑课次自动编号、日期计算周次和星期，新增沿用首节地点和时间并滚动定位；弹框顶部固定，仅内容区域滚动。

## 接口与数据

GET /api/timetable/:termId；个人课程覆盖接口

timetable_entries 的 base_snapshot_json、private_json、override_json、base_revision。
