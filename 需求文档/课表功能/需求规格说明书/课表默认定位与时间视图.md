# 课表默认定位与时间视图需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：本人；电脑和手机。

入口：我的课程 → 课程／课表 Tab。

## 当前规则

1. 菜单名为我的课程，默认打开课程卡片；课表为独立 Tab，保留原时间视图。
2. 电脑课表默认月视图，支持现有日、周、月、学期范围；手机只保留日、周，默认周视图，整周直接显示课程，不需逐日点击才能看到。
3. 按北京时间定位今天和当前学期；主动浏览其他日期后保留选择，点击回到今天恢复。
4. 课程、课表内都可打开课程详情；课表页面提供课表管理按钮，空态可居中点击导入课表。

## 接口与数据

GET /api/timetable/terms；GET /api/timetable/:termId

同一课表数据由电脑及手机各自界面展示。
