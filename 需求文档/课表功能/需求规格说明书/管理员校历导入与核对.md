# 管理员校历导入与核对需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：全部管理员；仅电脑。

入口：课程管理 → 学期与作息。

## 当前规则

1. 按完整学期统一计算教学周，只用一套主教学校历参与当前周次计算；原分段校历可保留为来源资料，不能混成两套周次。
2. 管理员配置学期起止、第一教学周及节次时间，支持复制校历 AI 提取提示词并粘贴结构化内容；没有内置 OCR 或 AI。
3. 课程编辑选择日期后自动计算周次和星期，用户不必自己填写；提示词和服务器共用写入代码的规则。
4. 数据不足时提示补齐，不能因月份跨年给无关课程补造日期；人工更改与已确认明确日期不得被宽泛修正。

## 接口与数据

学期管理、校历 prompt 及 example 接口

terms；shared/course-week.mjs 是完整学期计算规则。
