# 管理员模板删除需求规格说明书

更新：2026-11-09；与当前功能一致。

使用者：全部管理员；仅电脑管理入口。

入口：课程管理 → 课表模板 → 删除模板。

## 当前规则

1. 所有管理员可删除任意管理员创建的模板，提交模板 ID、当前版本与明确确认；普通用户和未完成首次改密的账号拒绝。
2. 删除后从管理列表和同学可选列表移除；保留已经选用者的现有课程、个人安排和课程作业。
3. 删除模板订阅及模板来源关联，必要时把用户现有课程保留为直接卡片来源；不删除公共卡片、课程和账号。
4. 取消不写入；旧版本、已删除或失效记录提示刷新，失败整笔回滚。

## 接口与数据

DELETE /api/admin/timetable/templates/:id

模板及订阅关系被删除，既有选课通过直接来源保留。
