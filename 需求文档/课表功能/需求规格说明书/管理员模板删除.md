# 管理员模板删除需求规格说明书

版本：V1.0；日期：2026-11-05；状态：本次修改已实现于本机，线上需另行更新。

角色：所有管理员可维护模板，普通学生无删除权限。

输入：模板标识、当前版本及明确删除确认。

输出：模板从管理员列表和学生选用列表移除；用户课程与作业保留。

## 业务规则

1. 每张管理员课表模板提供删除模板按钮，弹框展示模板名称并说明不可撤销；取消不写入。提交期间显示正在删除并阻止重复操作。
2. 后端只接受管理员请求，校验confirm=true和当前revision；普通学生拒绝，旧版本拒绝，已删除模板明确提示。不同管理员均可删除，不限制创建人。
3. 删除前同步模板最新成员，将该模板已选课程保留为直接卡片选课；保留原课程标识、私人资料与个人覆盖，不删除课程卡片、作业、完成状态、账号或其他模板。共享其他模板的课程同样保留。
4. 解除该模板的订阅与课程来源关系，清空个人课表对应模板标识与模板版本，增加受影响课表版本；其他模板的引用和同步继续有效。原课程仍随管理员卡片更新，个人覆盖继续优先。
5. 全部修改在同一数据库事务中完成，失败回滚。被删除模板不能再通过旧预览或接口选用，成功后刷新列表并通知个人课表更新。

## 数据与系统处理

复用timetable_templates、template_courses、timetables、timetable_entries、timetable_template_subscriptions及timetable_entry_templates，无新增表。直接来源设为cards，已有非空来源保留；仅删除目标模板及其引用。

接口：

- `DELETE /api/admin/timetable/templates/:id（revision、confirm=true）`

后端统一校验登录、角色、用户归属、目标学期和数据格式；有问题的预览需确认，写入按事务完成。

## 验收要点

- 学生、未确认和旧版本请求不改变数据。
- 删除后模板入口消失，已有课程、个人教室覆盖及作业完成状态保持。
- 另一个模板继续同步；管理员编辑原卡片后已选课程仍更新。
- 重复删除明确提示不存在，数据库外键检查通过。
