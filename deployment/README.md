# 代码上传与网站部署

代码已于 2026-11-05 首次上传至 https://github.com/lichen-lc123/class-assistant，主分支为 main。服务器为腾讯云，具体实例、系统和域名尚待确认；尚未连接服务器或发布网站。以下是 Linux + systemd + Nginx 的部署模板；确认服务器系统后再采用对应步骤。网站和后续小程序共用同一套后端和数据库。

## 1. Git 上传

提交源码、package-lock.json、需求说明和流程图。node_modules、dist、真实数据库及备份、环境配置、私钥和本地页面截图不提交。已有账户、课表、作业存放在本地 data 目录，不随代码上传。

origin 已设置为上述仓库，main 已跟踪 origin/main。仓库可见性保持原设置；不要把学号姓名、账号数据、密码、服务器凭据写入仓库。每次上传前用 git status 和 git diff --cached --stat 核对文件。

## 2. 服务器运行方式

使用 Node.js 24 或更高版本。后端使用 Node 内置 SQLite，不需要额外安装数据库服务；一期单实例即可。生产环境不要运行 Vite 开发服务器，也不要把 5173 或 3001 直接开放到公网。

构建可以在现有电脑完成：

```sh
npm run build
```

把 dist、server、shared、package.json 上传到服务器的 `/opt/homework/current`。生产进程仅使用 Node 内置模块，因此这份构建不需要在服务器安装 npm 依赖。如果在服务器构建，才需要用锁定文件安装构建依赖。

生产数据库单独保存为 `/var/lib/homework/homework.sqlite`，不放入代码目录。这样更新代码不覆盖数据。首次部署前先确定是迁移当前数据，还是新建空系统；不要自行复制真实用户数据到其他服务器，也不要在已有系统重复初始化管理员。

### 环境配置

将根目录 `.env.example` 作为模板，在服务器创建 `/etc/homework/homework.env`，替换真实 HTTPS 域名和数据库路径。环境文件不会自动加载；下方 systemd 服务读取该文件。它不应放入 Git。

需要专用系统用户和组 `homework`；应用目录允许该用户读取，数据库目录允许写入，环境文件由 root 管理并只允许必要用户读取。模板假定 Node 的实际路径是 `/usr/bin/node`，使用前通过 `command -v node` 核对。

### 进程与 HTTPS

`homework.service` 提供自动重启和开机启动模板，工作目录固定为 `/opt/homework/current`。由服务器管理员完成用户、目录、权限设置后，把它安装到 systemd，再启用服务。

`nginx.conf.example` 提供 HTTPS 反向代理模板。替换域名与有效证书路径，核对服务器已有配置，执行 Nginx 配置检查后才重载。没有有效证书时不要启用此模板。数据库及备份目录不得设为网站根目录。

现有登录限流按连接 IP 计数；经过单个反向代理时可能合并为服务器地址，集中输错密码会影响其他人。正式开放前需按实际代理拓扑配置可信来源 IP，再验证登录限流。本模板还不能直接视为已完成公网验收。

## 3. 数据迁移、备份与更新

备份脚本使用 SQLite 内置一致性备份，能够在运行时备份，避免只复制主文件遗漏 WAL 中尚未写回的数据：

```sh
node scripts/backup-database.mjs
```

脚本默认读本地 data；服务器上运行时须显式设置 DATABASE_PATH，或使用 Node 的 `--env-file` 参数加载生产配置，并将 scripts/backup-database.mjs 一并部署。也可传入备份目录作为第一个参数。备份含真实个人数据，只保留在有权限的存储中，不上传 Git。

首次迁移应先停止源系统写入，再生成一致性备份，把确定迁移的快照通过已授权的安全连接传到数据库位置，并检查权限。保留本地原数据。新服务器如果使用新数据库，才运行 server/manage.mjs init-admin，初始化内容通过不回显的标准输入提交。

更新前备份，代码与数据分开；更新后验证再开放。数据库结构可能随新版启动升级，回退旧代码前须核对是否兼容；不兼容时在停机状态恢复对应备份，避免边写入边覆盖数据库。

## 4. 上线验收

- HTTPS 登录、刷新、退出、改密及管理员入口正常。
- 普通学生无法调用管理接口，学生之间个人数据隔离。
- 学期、模板、个人课表、作业可以按实际账号权限使用。
- 上传表格与图片可以预览，错误文件不会写入正式数据。
- 重启进程后数据保留；备份可在隔离环境打开并恢复。
- 日志和访问地址中不包含密码或会话令牌。
- 提醒设置目前仅保存偏好；尚未接通真实手机通知，不得把设置成功当作已发送。

服务器系统与访问方式、域名/证书情况未确定之前，不执行远程部署。微信小程序尚未注册，主体类型按实际情况选择；账号注册、身份核验与备案可和开发并行推进。
